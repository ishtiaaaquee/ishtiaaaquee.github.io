## 🚀 Getting Started

### Local Development
1. Clone the repository
2. Open `index.html` in a modern web browser
3. No build process required - pure HTML, CSS, and JavaScript

### Customization
- Edit colors in `styles/variables.css`
- Modify layout in `index.html`
- Adjust animations in `styles/cyber-theme.css`
- Enhance interactivity in `scripts/enhanced-main.js`

## 📱 Responsive Breakpoints

- **Desktop**: 1200px and above (optimal experience)
- **Tablet**: 768px - 1199px
- **Mobile**: Below 768px (hamburger menu, stacked layout)

## ⚡ Performance Features

- **Smooth Scrolling**: Native CSS smooth scroll with JavaScript fallback
- **Lazy Animations**: Elements animate only when scrolled into view
- **Optimized Particles**: Efficient canvas-based particle system
- **Intersection Observer**: Modern API for scroll-triggered animations
- **CSS Transitions**: Hardware-accelerated animations
